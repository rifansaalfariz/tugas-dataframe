# Analisis Produksi Sampah Jawa Barat

## Sumber Data
Open Data Jawa Barat  
https://opendata.jabarprov.go.id/id/dataset/jumlah-produksi-sampah-berdasarkan-kabupatenkota-di-jawa-barat

## Tahapan Analisis
1. Membaca data CSV menjadi DataFrame
2. Menghitung total produksi sampah seluruh Jawa Barat (iterrows)
3. Menghitung total produksi sampah per tahun
4. Menghitung total produksi sampah per Kabupaten/Kota per tahun
5. Export hasil ke CSV dan Excel

## File Output
- total_sampah_per_tahun.csv
- total_sampah_per_tahun.xlsx
- total_sampah_per_kab_tahun.csv
- total_sampah_per_kab_tahun.xlsx
